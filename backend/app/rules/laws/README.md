# Undersign 법률 데이터베이스 (v2)

카메라로 계약서를 OCR한 뒤, 문장과 숫자를 법 조문·법정 수치와 대조하기 위한 데이터입니다.

## 출처
- **조문 원문**: 국가법령정보센터(law.go.kr) 원문을 Git으로 미러링한 공개 저장소 [legalize-kr](https://github.com/legalize-kr/legalize-kr)에서 가져왔습니다. 요약·의역 없이 원문 그대로입니다.
  - 각 법령 JSON의 `mirror_source.commit`/`file_url`로 정확한 버전을 추적할 수 있고, 조문마다 `source_url`(law.go.kr 조문 링크)이 붙어 있습니다.
  - law.go.kr에는 이 작업 환경에서 직접 접속할 수 없어서 미러를 거쳤습니다. 발표 전에 핵심 조문 몇 개는 law.go.kr에서 눈으로 대조해 보세요.
- **최저임금 금액**: 법령이 아니라 고용노동부 고시라서 언론 보도로 확인했습니다(`facts.json`의 `sources`).
  - 2026년 시간급 10,320원 / 2027년 시간급 10,700원(2026-08-05 고시, 2027-01-01 시행)
- v1(2차 출처 korea.legal에서 재조립한 10개 조문)은 `_archive/laws_v1_secondary_source.json`으로 옮겼습니다.

- **근로**: 근로기준법(+시행령·시행규칙), 최저임금법(+시행령), 근로자퇴직급여 보장법(+시행령), 기간제 및 단시간근로자 보호법(+시행령), 남녀고용평등법, 파견근로자보호법
- **주거 임대차**: 주택임대차보호법(+시행령), 주택임대차 확정일자 규칙, 민간임대주택특별법(+시행령), 전세사기피해자 특별법, 공인중개사법(+시행령·시행규칙)
- **상가 임대차**: 상가건물 임대차보호법(+시행령)
- **일반**: 민법 전체
- **소비자·약관**: 약관규제법(+시행령), 전자상거래법(+시행령), 방문판매법(+시행령), 할부거래법(+시행령), 소비자기본법
- **금전**: 이자제한법, 최고이자율 규정(연 20%), 대부업법(+시행령)
- **기타**: 대학 등록금에 관한 규칙, 주민등록법(+시행령), 전자서명법, 장애인차별금지법

## 주의
- **시행일이 아직 안 온 최신본**이 섞여 있습니다. 예: 최저임금법·기간제법 2026-12-08, 남녀고용평등법 2026-11-27, 할부거래법·민간임대주택법 2027-09-09. `effective_date`를 보고, 필요하면 앱에서 "곧 바뀌는 법" 표시를 해 주세요.
- 연장·야간·휴일 가산수당(LAB-008)은 상시 5명 미만 사업장에는 적용되지 않습니다. 앱에서 사업장 규모를 물어봐야 합니다.
- 소규모 수선비(HOU-007)는 판례상 특약으로 세입자 부담이 가능해서, 큰 수선만 경고하도록 적어 두었습니다.
- 이 데이터는 법률 자문이 아닙니다. 앱 안내 문구에도 "정확한 판단은 법률구조공단(132)·고용노동부(1350)에 문의"를 넣는 걸 권장합니다.

## 규칙 구조 (`check_rules.json`)
```json
{
  "id": "HOU-002",
  "doc_types": ["lease_housing"],
  "check": {"type": "numeric_max", "field": "rent_increase_ratio", "fact": "housing_rent_increase_cap"},
  "severity": "critical",
  "tts": "월세나 보증금을 5%보다 많이 올릴 수 있다는 조항이 있어요...",
  "refs": [{"law_name": "주택임대차보호법", "article_no": "제7조", "official_url": "https://www.law.go.kr/법령/주택임대차보호법/제7조"}]
}
```
`check.type`: `required_items`(필수 기재 누락) · `numeric_min` / `numeric_max`(OCR 숫자 비교) · `forbidden_clause`(무효 특약 키워드) · `info`(안내)
