# 저장된 사진의 전후 비교

2026-10-29, Windows / Python 3.11.9 / Tesseract 5.5.0.20241111 `kor` / Pillow 13.0.0 / OpenCV 5.0.0 / NumPy 2.4.6. 변경 전은 `6063a33be6f0500636f38257d0ccbcd6c0fa4694`, 변경 후는 이 결과와 함께 커밋된 구현이다. Google/Groq API는 호출하지 않았다.

가상 문서 내용 16개와 중복을 뺀 저장소 예시 이미지 8개를 여러 조건으로 변형한 **656장**을 평가했다. 실제 현장 사진이나 656종의 서로 다른 서식이 아니다. 각 실행은 `manifest.json`의 SHA-256을 검사해 같은 이미지 바이트를 사용한다. 분류 정답과 재촬영 기대 여부는 개선 전에 생성기에 기록했다.

## 결과

`정상 진행`은 정답 종류와 일치하고 불필요한 재촬영 요청이 없는 경우다. 미지원 종류의 올바른 `unknown`도 포함한다. 본문 전체가 정확하다는 뜻은 아니다.

| 시험 묶음 | 종류 분류 전 → 후 | 정상 진행 전 → 후 |
|---|---:|---:|
| 저장소 원본의 기존 변형 64장 | 56 → 62 | 51 → 60 |
| 저장소 원본의 추가 상황 48장 | 29 → 45 | 24 → 42 |
| 가상 문서의 추가 상황 96장 | 79 → 96 | 71 → 96 |
| 위 세 묶음 208장 합계 | **164 → 203** | **146 → 198** |
| 기존 기본 촬영 240장 | 240 → 240 | 239 → 240 |
| 기존 개발·내용 분리 장면 160장 | 160 → 160 | 160 → 160 |
| 읽을 수 있는 것으로 정한 608장 전체 | **564 → 603** | **545 → 598** |

- 별도의 읽기 실패 대조군 48장: 재촬영 탐지 **46 → 48**. 기호만 읽고 정상으로 통과하던 2건도 잡는다.
- 추가 가상 문서 96장의 문자 오류율(CER): **27.93% → 2.41%**. 정답 원문이 있는 사례만 계산하며 공백·구두점 등을 정규화한 편집 거리다. 저장소 예시 이미지에는 사람이 검수한 전체 전사 정답이 없어 CER를 계산하지 않았다.
- 모든 656장의 좌표 범위 검사 통과. 잘라내기·회전·기울기 역변환은 제목 마스크 8개와 추가 비교하여 IoU 0.825~0.900을 확인했다.
- 파이썬 단위 시험 39개(725개 텍스트 분류 변형 포함), 판단 엔진 smoke 시험 통과. 브라우저에서 샘플 656장과 검색 필터를 확인했다.

측정 시간은 여러 OCR 작업을 동시에 실행한 경과 시간이다. 처리 속도 비교를 위한 독립 벤치마크가 아니므로 성능 향상 수치로 사용하지 않는다. 정상 문서는 2회, 어려운 문서는 최대 14회 OCR 호출을 사용할 수 있다.
